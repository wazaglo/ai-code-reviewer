# Deployment

What it does: Makes it easy to install the whole system.

## In simple terms

This is the "一键安装" (one-click install) for the code reviewer.

Run the deploy script with your GitHub token and it will:
- Create all the AWS resources automatically
- Upload the code to the cloud
- Give you the webhook URL to connect your repository

## Why it matters

Instead of manually clicking through AWS to set up each part, one command builds the whole system.
